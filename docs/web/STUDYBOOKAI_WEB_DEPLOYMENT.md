# StudyBook AI Web Deployment

Status: `W4 PERSISTENT PROJECT READY - HUMAN CREATION REQUIRED`

## Vercel Project

```text
Root Directory: web/marketing
Framework Preset: Next.js
Install Command: pnpm install --frozen-lockfile
Build Command: pnpm build
Output: managed by Next.js/Vercel
Node.js: >=20.9.0
```

Required public environment values:

```text
NEXT_PUBLIC_WEB_URL=https://studybookai.com
NEXT_PUBLIC_APP_URL=https://app.studybookai.com
NEXT_PUBLIC_API_URL=https://api.studybookai.com
ENABLE_PUBLIC_INDEXING=false
CONTACT_DELIVERY_PROVIDER=disabled
CONTACT_DELIVERY_WEBHOOK_URL=<SERVER_ONLY_WHEN_APPROVED>
CONTACT_DELIVERY_WEBHOOK_SECRET=<SERVER_ONLY_WHEN_APPROVED>
```

Never place Supabase service role, OpenAI, Stripe or Google service-account
secrets in the marketing project. Contact delivery values are server-only and
must never use the `NEXT_PUBLIC_` prefix.

## Persistent Project Procedure

1. Create an authenticated Vercel project and select `web/marketing` as Root
   Directory.
2. Keep Production, Preview and Development variables separately scoped.
3. Set the three public URLs above. Keep `ENABLE_PUBLIC_INDEXING=false`.
4. Deploy a persistent Preview from the reviewed commit and repeat route,
   console, CSP, accessibility, responsive and contact failure-mode checks.
5. Select/configure the contact provider and distributed spam control in
   Preview before Production.
6. Confirm `app.studybookai.com` is deployed before treating account CTAs as
   available.
7. Resolve legal decisions and approve the legal pages.
8. Promote only after a separate production authorization. Set
   `ENABLE_PUBLIC_INDEXING=true` only in the approved Production environment.
9. Attach domains and apply only the exact DNS records generated by Vercel.

Do not invent DNS targets, use the temporary W3 URL as a project, or enable
indexing in Preview.

## Routing And Domains

Next.js owns route rendering; no Flutter-style SPA fallback is required.
`vercel.json` documents a permanent `www.studybookai.com` to apex redirect.
After a Vercel project exists, copy its exact DNS instructions. Do not invent
CNAME targets or IP addresses.
