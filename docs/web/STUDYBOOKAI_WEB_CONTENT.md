# StudyBook AI Web Content

Status: `W1 CONTENT BASELINE`

## Core Message

Headline: **Un documento. Todo tu aprendizaje.**

StudyBook AI converts user-selected documents into connected learning
experiences: summary, contextual chat, AudioBook, Voice Tutor, flashcards,
quizzes, question banks and exams.

## Audiences

- Students: comprehension, self-paced study, audio, practice and a personal
  library.
- Teachers: courses, students, planning, rubrics, question banks, exams,
  attendance, grades and weights.
- Institutions: contact-only conversation; no unsupported enterprise promise.
