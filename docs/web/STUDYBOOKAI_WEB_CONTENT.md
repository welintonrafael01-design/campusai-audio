# StudyBook AI Web Content

Status: `W2 PREMIUM CONTENT BASELINE`

## Core Message

Headline: **Un documento. Todo tu aprendizaje.**

StudyBook AI converts user-selected documents into connected learning
experiences: summary, contextual chat, AudioBook, Voice Tutor, flashcards,
quizzes, question banks and exams.

## Audiences

- Students: comprehension, self-paced study, audio, practice and a personal
  library.
- Teachers: courses, students, planning, rubrics, question banks, exams,
  attendance, grades and weights.
- Institutions: contact-only conversation; no unsupported enterprise promise.

## Commercial Catalog

- Free: USD 0.

- Teacher Pro: USD 13.99/month.
- Institution: contact.

The source of truth is `web/marketing/src/config/plans.ts`. Do not duplicate

Free is a discovery tier: 3 documents, 10 Chat IA messages, 3 summaries, one
flashcard set, and one quiz per UTC calendar month. It does not include
AudioBook, Voice Tutor, Question Bank, Exam Generator, or Teacher Studio.
Student Pro provides expanded AI learning access without an unlimited-use
claim. Teacher Pro adds Teacher Studio to the Student Pro learning foundation.
